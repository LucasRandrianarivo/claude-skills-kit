# Criteria — accuracy gates the edit

## Must do
- Flag the **unsourced 40%** as the primary problem and ask for the measurement (what was measured, on which route, before/after conditions) or require the figure to be cut. This must outrank the style fixes.
- Flag "significantly improved", "across the board", "substantially better" as unverifiable claims that need the specific numbers or removal.
- Question "confident that the remaining work will be delivered on schedule" — a schedule claim in a client report is a commitment and needs a basis.
- Produce an edited version that is direct and specific, and mark clearly where a number must be supplied.

## Should do
- Note the throat-clearing opener ("We are pleased to report that") and cut it.
- Keep the register appropriate for a client status report.
- Say that a polished paragraph carrying an unverified number is worse than an unpolished honest one.

## Must not do
- Return a smoother version of the same claims with the 40% intact and unquestioned.
- Add new specifics that were not in the source (invented routes, metrics, dates).
- Treat this purely as a style exercise.

## Scoring
1.0 — accuracy raised first and treated as blocking, vague claims flagged, edit marks what must be sourced.
0.5 — some claims questioned, but the 40% is carried through unchallenged.
0.0 — style-only polish.
